---
description: แสดงรายงานล่าสุดจาก reports/ (เช่นผล /blm ครั้งก่อน) ตามที่บันทึกไว้ในไฟล์
argument-hint: [ชื่อรายงาน เช่น businesslogic — ว่าง = ล่าสุดของทุกชื่อ]
---

1. เรียก `blm_report` โดย**ไม่ใส่ rows/content** และใส่ name = "$ARGUMENTS" (ว่าง = ไม่ใส่)
2. พิมพ์ `content` ที่ได้ออกมา**ทั้งหมดตามตัวอักษร** ห้ามสรุป ห้ามตัด แล้วปิดท้าย `ไฟล์: <file>`
3. ถ้า tool ตอบว่ายังไม่มีรายงาน บอกตามนั้นบรรทัดเดียว (ผู้ใช้เรียกตรงได้ด้วย `blm report`)
